Мои локальные серверы

Динамическое выделение отдельного порта CS2 Dedicated Server (27015, 27016, 27017...) под каждый матч

Как поднять реальный локальный CS2-сервер под каждый режим

Один установленный сервер CS2 можно запускать сколько угодно раз на разных портах (-port 27015, -port 27016) со своими конфигами.

1 Запуск сервера из папки CS2

Бэкенд webhook.js поднимает сервер сам. Для ручного запуска:

start "" "D:\Steam\steamapps\common\Counter-Strike Global Offensive\game\bin\win64\cs2.exe" -dedicated -usercon -insecure +game_type 0 +game_mode 1 +map de_mirage -port 27015 +rcon_password faceit123 +exec server.cfg
2 Установи плагины (Metamod + CSSharp + MatchZy)
  • • Metamod:Source 2.x — распакуй в game/csgo/addons/ и пропиши в gameinfo.gi.
  • • CounterStrikeSharp — движок C#-плагинов для CS2 (with-runtime).
  • • MatchZy — главный плагин для 5v5 и 1v1 (загрузка матча, раунды, !pause). Разминка и ножевой раунд отключены.
  • • CS2-Advertisement — автосообщения со ссылкой на сайт в чат.

Состав матча и подключение

Порт 27015 • Режим 5v5 • MatchZy

1. Состав матча

Состав, уровни и карта берутся из карточки матча. Сервер и загрузка матча выполняются бэкендом автоматически.

2. Скрипт запуска Windows (start_server.bat)

Создай файл start_27015.bat в папке CS2. Каждый матч запускается на своём уникальном порту!
