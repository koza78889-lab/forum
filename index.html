Локальный CS2 сервер

Настройки подключения для localhost / OpenCode плагинов. Сервер работает без VAC (-insecure).

Оставь пустым, чтобы использовать текущий URL браузера.

Команда запуска CS2 сервера (Без VAC) 
cs2.exe -dedicated -insecure -console -usercon +game_type 0 +game_mode 1 +map de_mirage +sv_lan 0 +ip 127.0.0.1 -port 27015
